# Athletix

Athletix is a full-stack sports e-commerce platform built from scratch using the MERN stack.

The goal of this project is not just to build an e-commerce website, but to understand how a real full-stack application works from the backend to the frontend.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Redux Toolkit

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication & Security
- JWT
- bcrypt

### External Services
- Stripe
- Cloudinary
- Nodemailer
